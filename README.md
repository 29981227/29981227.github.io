# 李欣瑶 Claire · 个人作品站修订版

## 打开方式

1. 完整解压本 ZIP，勿直接在压缩包预览窗口打开网页。
2. 打开根目录 `index.html`。
3. 点击项目卡片进入详情，向下滚动可操作内嵌 DEMO；也可点击“独立打开 DEMO”。手机上建议独立打开，以获得更大的原型操作空间。
4. 点击首页下载按钮获取对应 PDF。本地文件模式可能先打开 PDF 预览，可在预览页保存。

正式发布时，请完整上传站点目录，保留各文件夹名称和层级。网站为静态站点，无需安装依赖、构建或配置后台。两个作品集各约 40 MB，请确认托管服务允许该文件体积。

如已安装 Python，可在解压目录运行 `python -m http.server 8000 --bind 127.0.0.1`，然后打开 [本地预览](http://127.0.0.1:8000)。

## 文件结构

- `index.html`：首页与下载入口。
- `assets/css/`：首页、原型样式。
- `assets/js/`：项目文案、首页及原型交互。
- `assets/images/`：人物、原型插画与站点图标。
- `demos/`：三个独立交互原型。
- `downloads/`：两份真实 PDF 及放置说明。
- `验收报告.md`：本次已测范围与未测边界。
